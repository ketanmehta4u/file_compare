A short walkthrough, the supported data types, and common gotchas.

  1. Drop or choose your Source file (.csv or .xlsx) and click Load Source. Legacy .xls workbooks are not supported — re-save them as .xlsx.
  2. Do the same for the Target file.
  3. Under Comparison settings, check the column mapping, then pick the key columns that identify a row (an invoice or transaction id, say). Leave them unpicked to compare whole rows.
  4. Optionally open Matching options for numeric tolerance, case sensitivity and the rest — the defaults suit most comparisons, and the collapsed heading summarises whatever is in force.
  5. Optionally open Dataset catalogue if you have a catalogue workbook for a known dataset; it pre-fills the mapping, key columns and settings. It is not needed to compare two files.
  6. Click Run comparison. A progress bar reports the phase and row counts, and Cancel stops it.
  7. Read the verdict and summary. The tables are a preview; download the audit workbook for the complete result.
